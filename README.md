# Fatscore

Застосунок про здоров'я і фітнес з персонажем, який росте разом з тобою. Їжа, рух, вода, сон і звички дають досвід і монети, а персонаж за них еволюціонує, вдягається і мандрує картою.

Працює як PWA: відкривається в браузері, встановлюється на головний екран телефона, працює без інтернету. Усі дані зберігаються лише на пристрої.

## Як викласти на GitHub Pages (без програмування)

Готовий сайт уже зібраний у папці `docs`. Потрібно лише завантажити файли на GitHub і ввімкнути Pages.

### 1. Створи репозиторій
1. Зайди на [github.com](https://github.com) і увійди в акаунт.
2. Угорі праворуч натисни **+** → **New repository**.
3. **Repository name:** `fatscore` (або будь-яка інша назва латиницею).
4. Обери **Public**. На безкоштовному тарифі GitHub Pages працює лише з публічними репозиторіями.
5. Нічого більше не вмикай і натисни **Create repository**.

### 2. Завантаж файли
GitHub приймає до 100 файлів за один раз, тому завантажуємо в два заходи.

1. Розпакуй архів `fatscore.zip` на комп'ютері.
2. На сторінці нового репозиторію натисни посилання **uploading an existing file**.
3. **Перший захід:** відкрий розпаковану папку і перетягни у вікно браузера **лише папку `docs`** цілком (у ній 84 файли). Дочекайся, поки всі файли з'являться у списку. Унизу натисни **Commit changes**.
4. **Другий захід:** натисни **Add file → Upload files** і перетягни **все інше**: папки `src`, `public` і файли `index.html`, `package.json`, `package-lock.json`, `vite.config.ts`, `tsconfig.json`, `README.md`, `PROGRESS.md`. Натисни **Commit changes**.

> Якщо GitHub пише, що файлів забагато, розбий завантаження ще на менші частини. Важливо, щоб папка `docs` опинилась у корені репозиторію з усім вмістом.

### 3. Увімкни GitHub Pages
1. У репозиторії відкрий **Settings** (вкладка вгорі).
2. Ліворуч обери **Pages**.
3. **Source:** `Deploy from a branch`.
4. **Branch:** `main`, папка `/docs`. Натисни **Save**.
5. Зачекай 1–3 хвилини й онови сторінку. Угорі з'явиться адреса на кшталт `https://твій-логін.github.io/fatscore/`.

### 4. Встанови на телефон
- **iPhone (Safari):** відкрий адресу → кнопка «Поділитися» → **На початковий екран**.
- **Android (Chrome):** відкрий адресу → меню ⋮ → **Встановити застосунок** або **Додати на головний екран**.

Сканер штрихкодів просить доступ до камери. Камера працює лише за адресою `https://`, а GitHub Pages саме таку адресу і дає.

## Що вміє версія 0.1

- **Онбординг:** 18+, позначка «не медична порада», мета (схуднути, тримати вагу, набрати масу, просто звички), режим без цифр. Денна норма рахується за формулою Міффліна–Сан Жеора з безпечним мінімумом (1200 ккал для жінок, 1500 для чоловіків) і дефіцитом не більше 500 ккал.
- **3 персонажі:** Бурко, Шустра, Пампух. Кожен має свій характер і сотні реплік двома мовами. 5 стадій еволюції. Персонажі дихають, кліпають, стежать очима за пальцем, реагують на кожну дію і сплять уночі.
- **Їжа:** понад 140 страв і продуктів, з них 45 — українська та східноєвропейська кухня. Пошук в Open Food Facts і сканер штрихкодів (працює й на iPhone). Свої страви й рецепти з підрахунком порції. Улюблене, останні, «повторити вчорашнє». Калорії, БЖВ, клітковина. Тарілка дня, на якій з'являються страви.
- **Рух:** журнал силових з рекордами, 10 видів кардіо, 5 коротких тренувань з таймером (персонаж тренується разом з тобою), кроки, мапа подорожі Київ → Париж із сувенірами та фактами про міста, день відпочинку.
- **Самопочуття:** вода з м'ятою, що росте; сон; настрій; власні звички. На екрані прогресу — графік ваги, сон за тиждень, настрій за два тижні і зв'язок «рух — настрій».
- **Гра:** рівні, монети, 3 щоденні квести під твою мету, 28 досягнень (4 з них таємні), м'які серії з «днями запасу». Гардероб на 21 річ, зокрема фони кімнати, сезонні та легендарні речі. Без лутбоксів. Міні-гра «Лови овочі».
- **Святкування:** конфеті, звук, вібрація (на Android).
- **Налаштування:** три стилі оформлення на вибір (Тактильна кухня, Спортивна ризографія, Нічна кімната), кожен у світлій і темній темі; українська або англійська; зменшений рух; резервна копія у файл і відновлення з нього.

## Для розробника

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm test         # тести логіки
npm run build    # збірка в папку docs (її віддає GitHub Pages)
```

Стилі оформлення перемикаються атрибутом `data-style` на `<html>` і CSS-змінними в `src/styles/app.css`.

Стек: React 19, TypeScript, Vite, Motion (пружинні анімації), Dexie (IndexedDB), vite-plugin-pwa, barcode-detector (zxing-wasm), шрифти Unbounded, Onest, Dela Gothic One, Golos Text, Alegreya, Manrope (@fontsource, ліцензія OFL).

Дані про продукти: [Open Food Facts](https://world.openfoodfacts.org), ліцензія ODbL. Персонажі, іконки й ілюстрації оригінальні, намальовані кодом.

**Важливо:** Fatscore не є медичною порадою. Застосунок для дорослих 18+.
