# Fatscore

Застосунок про здоров'я і фітнес з персонажем, який росте разом з тобою. Їжа, рух, вода, сон і звички дають досвід і монети, а персонаж за них еволюціонує, вдягається і мандрує картою.

Працює як PWA: відкривається в браузері, встановлюється на головний екран телефона, працює без інтернету. Усі дані зберігаються лише на пристрої.

## Як викласти на GitHub Pages (без програмування)

Готовий сайт уже зібраний у папці `docs`. Потрібно лише завантажити файли на GitHub і ввімкнути Pages.

### 1. Створи репозиторій
1. Зайди на [github.com](https://github.com) і увійди в акаунт.
2. Угорі праворуч натисни **+** → **New repository**.
3. **Repository name:** `fatscore` (або будь-яка інша назва латиницею).
4. Обери **Public**. На безкоштовному тарифі GitHub Pages працює лише з публічними репозиторіями.
5. Нічого більше не вмикай і натисни **Create repository**.

### 2. Завантаж файли
GitHub приймає до 100 файлів за один раз, тому завантажуємо в два заходи.

1. Розпакуй архів `fatscore.zip` на комп'ютері.
2. На сторінці нового репозиторію натисни посилання **uploading an existing file**.
3. **Перший захід:** відкрий розпаковану папку і перетягни у вікно браузера **лише папку `docs`** цілком (у ній 95 файлів). Дочекайся, поки всі файли з'являться у списку. Унизу натисни **Commit changes**.
4. **Другий захід:** натисни **Add file → Upload files** і перетягни **все інше**: папки `src`, `public` і файли `index.html`, `package.json`, `package-lock.json`, `vite.config.ts`, `tsconfig.json`, `README.md`, `PROGRESS.md`. Натисни **Commit changes**.

> Якщо GitHub пише, що файлів забагато, розбий завантаження ще на менші частини. Важливо, щоб папка `docs` опинилась у корені репозиторію з усім вмістом.

### 3. Увімкни GitHub Pages
1. У репозиторії відкрий **Settings** (вкладка вгорі).
2. Ліворуч обери **Pages**.
3. **Source:** `Deploy from a branch`.
4. **Branch:** `main`, папка `/docs`. Натисни **Save**.
5. Зачекай 1–3 хвилини й онови сторінку. Угорі з'явиться адреса на кшталт `https://твій-логін.github.io/fatscore/`.

### 4. Встанови на телефон
- **iPhone (Safari):** відкрий адресу → кнопка «Поділитися» → **На початковий екран**.
- **Android (Chrome):** відкрий адресу → меню ⋮ → **Встановити застосунок** або **Додати на головний екран**.

Сканер штрихкодів просить доступ до камери. Камера працює лише за адресою `https://`, а GitHub Pages саме таку адресу і дає.

## Що вміє версія 0.2

**Навігація.** Головна · Щоденник · «+» · Пригоди · Герої. Їжа, Рух, Маршрут, Профіль і Друзі відкриваються окремими сторінками з кнопкою «назад».

- **Головна з віджетами.** 15 віджетів: герой, тарілка, вода, рух, денні й тижневі завдання, сезон, серія, сон, настрій, звички, щоденник, подорож, вага, міні-гра. Кнопка «Налаштувати головну» дає змогу додавати, прибирати й пересувати віджети.
- **Щоденник.** Календар місяця, де кожен день позначено кольоровими крапками (їжа, вода, рух, запис), а настрій підсвічує день кольором. Для будь-якого дня є нотатки, фото дня, настрій і сон. Можна дописати їжу за минулий день, якщо забув. Також тут підсумок тижня і тренди: сон, настрій за 4 тижні, вага, зв'язок «рух — настрій».
- **Пригоди.**
  - Сезон «Затишна осінь», далі «Зимова казка» і так далі: 10 рівнів нагород, сезонні речі й сезонні досягнення.
  - 3 денні та 3 тижневі завдання.
  - 104 досягнення (97 у 27 серіях від бронзи до діаманта і 7 таємних) плюс 3 сезонні щосезону, з намальованими значками, прогресом і фільтрами.
  - Мапа подорожі Київ → Париж.
- **Герої.**
  - 6 героїв: Бурко, Шустра, Пампух, а ще лисиця Лиска, кіт-кухар Мурчик і сова Софа.
  - Кожен має свій рівень і 5 стадій еволюції. Досвід отримує герой, який зараз поруч.
  - Нові герої відкриваються за досягнення або за зірки.
  - Гардероб на 35 речей, усі пасують кожному героєві.
- **Валюти.** Монети йдуть на речі. Зірки дають тижневі завдання, досягнення й сезон, ними відкривають героїв. Без лутбоксів і без реальних грошей.
- **Їжа.**
  - Пошук у вбудованій базі та в Open Food Facts, сканер штрихкодів.
  - Запис повідомленням: «2 сирники, кава з молоком і банан» розбирається без ШІ.
  - Свої страви й рецепти, улюблене, «повторити вчорашнє».
- **Рух.**
  - Силові тренування з рекордами, кардіо, короткі тренування з таймером, кроки.
  - Запис маршруту через GPS з мапою OpenStreetMap.
  - Імпорт тренувань із годинника у форматі GPX або TCX: Garmin, Strava, Polar, Coros, Suunto, Samsung Health.
- **Профіль.**
  - 3 стилі оформлення, теми й мови.
  - «Спокійний режим» прибирає лічильник серій. «Режим без цифр» прибирає калорії й вагу.
  - Резервна копія у файл.
- **Друзі.** Код друга й «Поділитися підсумком тижня» працюють уже зараз. Друзі, чат, спільні цілі й ліги — у наступному етапі, з сервером.

## Для розробника

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm test         # тести логіки
npm run build    # збірка в папку docs (її віддає GitHub Pages)
```

Стилі оформлення перемикаються атрибутом `data-style` на `<html>` і CSS-змінними в `src/styles/app.css`.

Стек: React 19, TypeScript, Vite, Motion (пружинні анімації), Dexie (IndexedDB), vite-plugin-pwa, barcode-detector (zxing-wasm), Leaflet + OpenStreetMap, шрифти Unbounded, Onest, Dela Gothic One, Golos Text, Alegreya, Manrope (@fontsource, ліцензія OFL).

Дані про продукти: [Open Food Facts](https://world.openfoodfacts.org), ліцензія ODbL. Персонажі, іконки й ілюстрації оригінальні, намальовані кодом.

**Важливо:** Fatscore не є медичною порадою. Застосунок для дорослих 18+.
