## Ключові рішення
- **2D замість 3D:** простіше масштабувати одяг на всіх персонажів, легко працює на слабких телефонах. Усі персонажі мають спільний «скелет» (голова в точці 120,92 на полотні 240×260), тому кожна річ пасує кожному.
- **Палітра:** масло `#FFF1D6`, томат `#E5462B`, гірчиця `#F0B429`, оливка `#6F7F2E`, персик `#FFB892`, баклажан `#3B1E3F`. Темна тема окрема, баклажанова.
- **Шрифти:** Unbounded (заголовки, цифри) і Onest (текст), обидва з повною кирилицею, вбудовані в збірку.
- **Дані** лежать у IndexedDB (Dexie), одним об'єктом стану (`src/store.ts`). Записи їжі зберігають знімок продукту, тому працюють офлайн.
- **Безпека:**
  - нагороди даються за записи й різноманітність, ніколи за «з'їв менше»;
  - денна норма не нижча за 1200 ккал для жінок і 1500 для чоловіків, дефіцит не більший за 500 ккал;
  - якщо три дні поспіль виходить менше 60% норми, з'являється м'яке повідомлення про турботу;
  - день відпочинку зараховується як активний;
  - персонаж ніколи не сумує й не соромить.
- **Анти-«фарм»:** на більшість винагород є денні ліміти (`CAPS` у `src/logic/game.ts`).
- **Без лутбоксів:** гравець бачить річ і купує саме її; легендарні речі можна лише заробити.
- **Назва Fatscore** поки залишається. Ризик: назва зі словом «fat» може бути тригером для людей зі схильністю до розладів харчування і насторожити модерацію магазинів застосунків. Повернутися до питання перед публікацією в магазинах.

## Структура
```
src/
  data/       foods, characters, items (речі й досягнення), exercise (вправи, міста)
  logic/      nutrition (норма), game (рівні, квести, серії, нагороди), dates, тести
  services/   off (Open Food Facts), scanner (камера + zxing), feedback (звук, вібрація)
  components/ art (персонажі, речі, тарілка, рослина), Icon, ui (шторки, тости, святкування)
  screens/    Onboarding, Home, Food, Move, Wardrobe, Profile, MiniGame
docs/         зібраний сайт для GitHub Pages (генерується командою npm run build)
```

## Як оновлювати сайт
1. Зміни код у `src/`.
2. Виконай `npm run build`: оновиться папка `docs/`.
3. Завантаж нову папку `docs/` у репозиторій.
